$ cat overview.md

The overview.

Real-time market data is noisy, fragmented, and fast. Most retail trading tooling either shows delayed charts or hides its logic inside a black box — traders get lines on a screen, not reasoning they can act on. I wanted to build the opposite: a platform that streams live data, explains its own signals, and quantifies risk instead of just drawing lines.

QuantLab — deployed publicly as QuantTrade — is that platform. It's an AI-driven trading intelligence system I designed and built entirely on my own, from the database schema up through the API to the user interface, and it has been live in production since 2023. Every part of the stack is mine: the real-time pipeline, the analysis engine, the AI integrations, and the dashboard traders actually look at.

The project doubles as my proving ground for full-stack engineering under real constraints — latency budgets, production uptime, and a UI that has to stay readable while data never stops moving.

$ cat architecture.md

How it's built.

Six subsystems, one coherent pipeline: raw market data flows in over WebSockets, gets analyzed autonomously, gets simulated probabilistically, and lands on a dashboard where AI explains what it all means.

⌁ Real-time data pipeline

A multi-source real-time pipeline streaming market data over WebSockets, with custom caching so the UI never waits on a round trip and never drops a tick.

WebSocketsNode.js

◈ Neural intelligence core

A custom neural core running autonomous analysis cycles — continuously identifying market regimes and alpha opportunities without manual prompting.

TypeScriptCustom ML

∑ Monte Carlo engine

A simulation engine in TypeScript forecasting outcomes across thousands of stochastic paths per run, with dynamic confidence intervals so every forecast carries its own uncertainty.

TypeScriptStochastic modeling

✦ AI analytics & risk modeling

Google Gemini 1.5 Pro wired directly into the live dashboard for real-time predictive analytics and risk modeling — signals come with explanations, not just numbers.

$ cat engineering.md

Engineered like production.

  • Clean REST API contracts. Every endpoint is documented and versioned; the frontend never guesses at a response shape, so integrations stay stable as the platform grows.
  • Testing as a quality gate. Unit, integration, and end-to-end tests run as CI/CD gates on GitHub Actions — nothing merges or deploys green unless the pipeline says so.
  • Responsive, validation-driven UX. The dashboard adapts from desktop to mobile, and every input is validated before it can touch the pipeline — bad data is rejected at the edge, not debugged in production.
  • Continuous deployment. GitHub auto-deploy keeps the live app at quant-trade-neon.vercel.app in lockstep with the main branch — every push is a release candidate.
